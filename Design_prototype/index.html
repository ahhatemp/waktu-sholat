Layar 01

Harian

Satu informasi utama: sholat berikutnya dan hitung mundurnya. Daftar di bawahnya mendukung, bukan bersaing.

  • NextPrayerCard memakai primary; badge “Berikutnya” memberi penanda kedua selain warna.
  • Baris berikutnya memakai primaryContainer dan teks lebih tebal.
  • Angka jam dan hitung mundur memakai tnum agar tidak bergoyang.
  • Banner izin memakai warningContainer dan hilang setelah izin aktif.
  • Ikon lonceng membedakan bentuk aktif/nonaktif, bukan hanya warna.

Token utama

primary primaryContainer accentContainer warningContainer
  • Target sentuh minimum 48 dp, termasuk ikon lonceng.
  • Hitung mundur dibacakan sebagai kalimat oleh TalkBack.

Layar 02

Bulanan

Tabel penuh untuk merencanakan jauh hari, dihitung offline dan bisa digulir.

  • Hari ini ditandai latar primaryContainer dan bilah primary di kiri.
  • Kolom tanggal tetap sempit; lima waktu wajib menjadi fokus.
  • Navigasi bulan sebelumnya/berikutnya berupa tombol 40 dp dengan area sentuh 48 dp.
  • Catatan metode dan koreksi menjaga kepercayaan pada angka.

Token utama

surface surfaceVariant primary

Layar 03

Pengaturan

Dikelompokkan per kebutuhan agar tidak terasa banyak. Setiap baris minimal 56 dp dan seluruh baris dapat disentuh.

  • Tema memakai segmented control; widget ikut berubah.
  • Ihtiyath memakai stepper kecil agar nilai mudah dibaca.
  • Panduan baterai tetap dapat dibuka ulang kapan saja.
  • Toggle memakai track primary dan label teks, bukan warna saja.

Token utama

surface outlineVariant primary

Layar 04

Cari Kota

Alternatif saat izin GPS ditolak. Database kota dibundel di dalam aplikasi, jadi pencarian tetap berjalan tanpa internet.

  • Kolom pencarian berbentuk pil; fokus memunculkan batas 2 dp primary.
  • Setiap hasil menampilkan kota dan provinsi dengan tinggi 56 dp.
  • Kota terpilih ditandai ikon centang selain latar.
  • Coba ketik “band” atau “sura” pada prototipe.

Token utama

search.bg search.border.focus divider

Layar 05

Onboarding

Empat langkah singkat: lokasi, notifikasi, baterai, selesai. Setiap izin bisa dilewati dan diatur ulang nanti.

  • Ilustrasi hanya ikon vektor, tanpa aset bitmap besar.
  • Indikator langkah memakai empat titik; titik aktif memanjang.
  • Tombol “Lewati” adalah text button agar tidak bersaing dengan aksi utama.
  • Target selesai di bawah satu menit.

Token utama

primaryContainer accent onSurfaceVariant

Layar 06

Widget

Pratinjau layar utama Android: widget kecil 2×1 dan widget besar 4×2. Keduanya memakai token yang sama dengan aplikasi.

  • Baris berikutnya disorot widget.highlight.bg dengan teks tebal.
  • Radius mengikuti sistem pada Android 12+; sebelumnya 16 dp.
  • Seluruh widget dapat disentuh untuk membuka aplikasi.
  • Kondisi khusus: “Atur lokasi”, “Jadwal tidak tersedia”, dan “Sekarang”.

Token utama

widget.bg highlight.bg text.secondary
